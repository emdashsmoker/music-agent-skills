# 작곡과 편곡

## 작업 순서
- 큰 결정에서 작은 결정 순서로 진행
    + 장르, 템포, 조
    + 곡 구성 (섹션 목록과 마디 수, 섹션별 에너지)
    + 코드 진행
    + 리듬 (드럼, 베이스)
    + 주선율과 훅
    + 보조 성부 (아르페지오, 패드, 대선율)
    + 전환 (필인, 라이저, 필터 움직임)
- 단계마다 `lint`로 확인한 뒤 다음 단계로 진행
    + 화성 오류를 늦게 발견할수록 고칠 범위가 커짐

## 곡 길이
- 4/4 박자 한 마디의 길이는 `240 / bpm`초
    + 128 bpm : 1.875초, 3분 30초는 112마디
    + 138 bpm : 1.74초, 7분은 242마디
    + 174 bpm : 1.38초, 4분은 174마디
- 섹션은 4, 8, 16, 32마디 단위가 기본
- 장르별 표준 구성은 `genres <id>`의 Arrangement 항목 참조

## 코드 진행
- 한 곡에 진행은 2-3개면 충분
    + 벌스용, 코러스용, 브리지용
    + 전자음악은 같은 진행을 유지한 채 음색과 밀도로 전개하는 경우가 많음
- 단조 장르의 기본 진행
    + `i | VI | III | VII` : 장화음 VI와 III가 단조에 밝은 색을 더하는 순환
    + `VI | VII | i | i` : 상승감, 코러스와 클라이맥스
    + `i | iv | VI | V` : 긴장감 (V는 화성단음계의 장3화음)
    + `i | i | bVII | bVII` : 한 코드 장르의 작은 움직임
- 코러스는 벌스와 다른 코드로 시작하면 구분이 분명해짐
- 로마 숫자로 작성하면 조를 바꿔도 진행이 유지됨
- 화성 리듬은 섹션 성격에 맞춰 선택
    + 2마디 한 코드 : `Am | % | F | %`, 느린 화성 변화
    + 한 마디 두 코드 : `Am F | C G`, 빠른 화성 변화
    + 박 단위 지정 : `Am | Am:3 G:1`, 마디 끝의 짧은 경과 코드
- 색채 코드 1개를 bridge나 prechorus 끝에 배치 가능
    + 7화음, sus4, add9, 차용 화음 중 하나 (`Gsus4`, `Fadd9`, 단조 곡의 `IV`)

## 선율
- 강박(첫 박, 셋째 박)의 음은 코드 구성음 위주로 배치
    + 경과음과 이웃음은 약박에 배치
- 코드음 바로 위 반음을 길게 끌지 않음
    + 단3화음에서 장3도, 장화음에서 4도가 대표적
- 순차 진행을 기본으로 하고 도약은 한 프레이즈에 한두 번
    + 도약 뒤에는 반대 방향 순차 진행으로 받음
- 프레이즈 끝은 코드의 근음, 3음, 5음 중 하나
    + 근음은 종결감, 5음은 이어지는 느낌
    + 근음 종결은 섹션의 마지막 프레이즈에 사용, 나머지 프레이즈 끝은 3음이나 5음 위주
- 훅은 2마디 안팎의 동기를 반복하고 끝만 바꿈
    + 같은 동기를 다른 코드 위로 옮기기가 가장 쉬운 발전 방법
- 프레이즈 길이는 비대칭(2+2+4마디, 3+5마디)도 허용
    + 보컬곡은 가사 행 길이를 따름
- 코러스 선율은 벌스보다 3도에서 5도 높은 음역에 배치

## 베이스
- 코드가 바뀌는 자리에서는 근음을 연주 (슬래시 코드는 베이스음)
- 킥과 같은 자리의 베이스 음은 짧게 연주하거나 비움
    + 포온더플로어 장르의 뒷박 베이스와 롤링 베이스(`. 1 1 1`)가 이 원리를 따름
- 음역은 E1에서 C3 사이가 기본
    + 그보다 낮으면 대부분의 재생 장치에서 들리지 않음

## 음역 배치

| 역할 | 권장 중심 음역 | lint 허용 범위 |
|---|---|---|
| sub | E1 - E2 | C1 - D3 |
| bass | E1 - C3 | D1 - C4 |
| pad | C3 - C5 | E2 - E6 |
| chord | C3 - C5 | G2 - E6 |
| keys | C2 - C6 | A1 - D7 |
| arp, pluck | C3 - C6 | C3 - D7 |
| lead | C4 - C6 | E3 - D7 |
| vocal | 목소리의 말하는 음높이에서 위로 한 옥타브 이내 | 엔진별 확인 |

- C3 아래에서는 5도보다 좁은 음정을 겹치지 않음
- 한 옥타브 폭(G3-C5)에 선율 성부가 셋 이상 몰리면 서로 가림
    + 옥타브를 나누거나 하나를 뺌

## 편곡의 에너지 설계
- 섹션마다 `energy`(0-1)를 먼저 정함
    + intro 0.3, verse 0.5, build 0.7, chorus 0.9, drop 1.0이 출발점
    + 대비 구간(bridge, break)은 chorus와 drop보다 낮으면 충분하며 verse보다 낮을 필요는 없음
- 에너지를 올리는 수단
    + 트랙 수 추가 (특히 하이햇, 라이드, 클랩)
    + 필터 열기 (`auto`의 `lpf`)
    + 음역 확장 (옥타브 위 성부 추가)
    + 리듬 세분화 (8분 하이햇에서 16분 하이햇)
- 에너지를 내리는 수단
    + 필터 닫기, 성부 수 줄이기, 리듬 밀도 낮추기
- 대비 구간은 앞뒤 섹션과 다른 느낌으로 귀를 환기하는 구간
    + 대비는 리듬, 화성, 음색, 편성 가운데 어느 수단으로도 만듦
    + 파트를 빼는 방식은 편성 수단의 한 가지
- 대비 구간의 장치는 다음 순서의 근거로 선택
    + 1순위 : 사용자 지시
    + 2순위 : `genres <id>`의 Arrangement 항목 (읽는 기준은 아래 항목)
    + 3순위 : 곡 고유 입력 (가사의 전환점, 분위기, 레퍼런스, 템포, 길이)
    + 고른 장치, 근거 한 줄, 비교한 장치 1개를 기획 요약과 `notes`에 기록
    + 비교한 장치는 고른 장치와 다른 수단에서 고름
    + 근거 한 줄에는 사용자 지시, Arrangement 원문 인용, 곡 고유 입력 중 해당 내용을 적음
- 장르 파일의 `song` 스타터는 2단계 문법의 출발점이며 장치 선택의 근거로 쓰지 않음
- 2순위의 Arrangement 문구는 적힌 내용의 범위에서 근거로 사용
    + 파트를 빼거나 바꾸는 장치는 그 동작을 직접 적은 문구를 근거로 사용 (darksynth의 `half-time breakdown`, disco의 `breakdown strips to bass and strings`)
    + 남는 파트를 나열한 문구(futurepop의 `with pads and vocal` 등)는 그 파트를 포함하라는 근거로 사용
    + 이름만 적은 문구(`break`, `breakdown`, `bridge`)는 장치를 정하지 않은 상태로 보고 3순위로 진행
- 3순위 근거는 곡 고유 입력을 이 구간이 맡을 효과 하나로 옮긴 뒤 그 효과를 얻는 장치에 연결
    + 효과의 예 : 무게, 숨 고르기, 국면 전환, 끊김 없는 추진, 리듬 노출, 부유감, 정적
- 대비 구간 장치 (노래 형식과 클럽 형식 공통, `energy`는 실제 밀도로 정함)
    + 장치마다 얻는 효과와 잃는 효과가 함께 있음
    + [리듬] 하프타임 : 드럼 유지, 스네어를 3박으로 옮기고 베이스는 긴 음 / 얻는 효과는 무게와 느려진 걸음, 잃는 효과는 질주감
    + [리듬] 성긴 킥 : 킥을 마디 첫 박이나 1박과 3박에만 두고 햇과 퍼커션도 성기게 연주 / 얻는 효과는 맥박을 남긴 숨 고르기, 잃는 효과는 그루브의 밀도
    + [화성] 화성 전환 : 드럼 유지, 벌스와 다른 `chords`나 `transpose` 전조 / 얻는 효과는 정서의 국면 전환, 잃는 효과는 에너지의 낙차
    + [음색] 필터 드럼 : 드럼 트랙의 `lpf`를 낮춰 둔탁하게 둠 / 얻는 효과는 끊김 없는 추진, 잃는 효과는 대비의 크기
    + [편성] 드럼만 남김 : 화성 성부 제거, 드럼과 퍼커션 위주 / 얻는 효과는 리듬의 노출과 화성 공백의 긴장, 잃는 효과는 선율과 화성의 흐름
    + [편성] 킥만 비움 : 베이스, 햇, 패드 유지 / 얻는 효과는 바닥이 떠오르는 부유감과 베이스 선율의 노출, 잃는 효과는 박의 무게
    + [편성] 킥과 베이스 제거 : 패드와 주제 선율만 남김 / 얻는 효과는 가장 큰 대비와 정적 속 선율의 노출, 잃는 효과는 맥박
- 클럽 형식(chorus 없이 build와 drop으로 짠 구성)의 break도 같은 근거 순서로 장치를 고름
    + 킥 없는 break는 Arrangement 문구가 킥 제거를 적은 장르에서 2순위 근거를 가짐
    + 싣는 내용 변주 : 주제 선율 예고, 새 진행, 보컬, 퍼커션
    + 길이 변주 : 장르 관습 안의 8, 16, 32마디
    + 두 번째 드롭 변주 : 아래 '같은 섹션이 다시 나올 때'의 변경 한 가지
- 전환 장치
    + 섹션 끝 : `rise`의 riser, snare_roll, reverse_crash
    + 섹션 시작 : `hit`의 crash, impact
    + 드롭 직전 한 마디 또는 한 박 동안 킥을 비움 (`gap`)
    + 브레이크 시작 : `hit`의 downlifter, `auto`의 필터 닫힘, 장치 없음 중 선택
- 같은 섹션이 다시 나올 때는 한 가지를 바꿈
    + 성부 추가, 화음 추가, 필인 변경, 옥타브 이동 중 하나
- QA가 섹션별 실제 음량 순위와 `energy` 순위를 비교하므로 기획과 결과의 차이를 확인 가능

## 곡의 끝
- 끝 처리는 편곡의 일부
    + 마지막 마디까지 가득 연주하고 멈추면 음악이 잘린 것처럼 들림
- 세 가지 방법 중 하나를 선택
    + 끝맺음 타격 : `ending: hit`, 으뜸화음 한 번과 감쇠 (클럽 장르, 팝)
    + 페이드아웃 : `ending: fade`, 반복형 아웃트로 (로파이, 두머, 신스웨이브 등)
    + 직접 작성 : 성부를 줄여 가는 아웃트로와 마지막 화음
- 아웃트로에서 필터를 닫거나 음량을 내린 경우에도 마지막 지점을 정함
    + 닫힌 채로 끝나는 잔향은 유지되므로 마지막 타격 또는 페이드와 함께 사용

## 그루브
- `swing` : 16분 뒷자리를 늦춤 (하우스 0.04-0.1, 힙합 0.15-0.3)
- `humanize: {timing_ms: 5}` : 기계적 정확함이 장르 특성이면 0으로 둠
- 세기 변화가 그루브의 절반
    + 하이햇 패턴에 `x`와 `o`를 섞음
    + 스네어 고스트 노트는 `o`
- 엇박은 악기 파트에 적용 (베이스, 스탭, 햇 액센트, 보컬 휴지에 응답하는 리드)
    + 연주곡은 리드 훅의 당김음(3-3-2 리듬, 선행음)까지 허용
    + 보컬 음절의 배치는 `vocals.md`의 규칙을 따름

## 보컬 곡의 편곡
- 보컬이 부르는 동안 같은 음역의 리드는 쉼
    + 리드는 보컬 줄 끝의 긴 음이나 쉼표 자리에서 응답
- 벌스는 드럼, 베이스, 가벼운 아르페지오 정도로 비움
- 코러스에서 패드와 스탭을 더하되 보컬 음역(C4-A4 부근)에 지속음을 쌓지 않음
- 화음과 더블은 코러스에만 사용

## lint 항목 해설

| 코드 | 뜻 | 대응 |
|---|---|---|
| `key.outside` | 조와 코드 어디에도 속하지 않는 음 | 의도한 반음계인지 확인, 비율이 15%를 넘으면 경고 |
| `harmony.avoid_note` | 코드음 반음 위의 긴 음 | 음을 바꾸거나 짧게 하거나 약박으로 이동 |
| `harmony.strong_beats` | 강박의 음 중 코드음 비율이 절반 미만 | 강박 음을 코드음으로 조정 |
| `bass.off_chord` | 코드가 바뀌는 자리의 베이스가 코드음이 아님 | 근음 또는 5음으로 변경 |
| `clash.semitone` | 두 트랙이 반음 간격으로 길게 겹침 | 한쪽 음 변경 |
| `range.<역할>` | 역할의 통상 음역을 벗어난 음 | `octave` 조정 |
| `mud.low_voicing` | C3 아래의 좁은 음정 | 보이싱을 올림 |
| `mono.chord` | 단음 악기에 화음 입력 | 악기 교체 또는 단선율로 변경 |
| `melody.leap` | 한 옥타브를 넘는 도약 (보컬은 장6도 초과) | 의도 확인 |
| `density.register` | 같은 음역에 성부 과밀 | 옥타브 분산 또는 성부 삭제 |
| `structure.flat` | 섹션 에너지가 전부 비슷함 | 대비 추가 |
| `structure.odd_length` | 홀수 마디 섹션 | 의도 확인 |
| `structure.short` | 곡 길이가 스케치 수준 | 구성 확장 |
| `structure.no_ending` | 마지막 마디까지 연주가 이어지고 끝 처리가 없음 | `ending: hit` 또는 `ending: fade`, 또는 끝맺음 섹션 작성 |
| `chords.missing` | 코드 정의 없음 | 화성 검사를 받으려면 `chords` 지정 |
| `vocal.overlap` | 가사 줄이 서로 겹침 | 줄 길이 또는 시작 위치 조정 |
| `lyrics.*` | 가사 관련 | `vocals.md` 참조 |

- 오류(ERROR)는 렌더 전에 반드시 해결
- 경고(WARN)는 하나씩 판단
    + 의도한 불협화나 장르 관습이면 유지
    + 판단 근거를 곡 파일의 `notes`에 남기면 다음 작업 때 같은 고민을 반복하지 않음
- 정보(INFO)는 참고 사항
